# 调用 LLM API

TextGO 可以调用本地或在线 AI 模型，完成翻译、改写、摘要和问答等任务。

## 功能概述

提示词模板可以：

- 使用本地或在线 AI 模型处理文本
- 创建自定义提示词模板

支持的模型提供商：

**本地：**

- [Ollama](https://ollama.ai/)
- [LM Studio](https://lmstudio.ai/)

**在线：**

- [OpenRouter](https://openrouter.ai/)
- [OpenAI](https://openai.com/)
- [Anthropic](https://www.anthropic.com/)
- [Gemini](https://gemini.google.com/)
- [xAI](https://x.ai/)

还可以在“自定义”区域填写“名称”“API 地址”和“API 密钥”，添加兼容 OpenAI 接口的自定义提供商。

在“AI 对话”页面打开“模型提供商选项”，配置本地服务地址、云端 API Key 和自定义提供商：

![TextGO 模型提供商选项](/screenshots/zh-CN/model-provider-options.png)

## 创建提示词模板

### 步骤 1：进入 AI 对话配置

1. 打开“设置”>“AI 对话”
2. 点击“+”按钮打开“新增提示词模板”窗口

### 步骤 2：基本信息

**动作名称**（必填）

- 标识提示词模板
- 建议使用描述性的名称

**动作图标**（可选）

- 点击当前动作图标打开图标选择窗口
- 可选择“内置图标”或“上传自定义 SVG”

**模型提供商**（必填）

- 选择本地、在线或自定义模型提供商
- 在线提供商需先在“模型提供商选项”中填写 API Key

**模型名称**（必填）

- 输入提供商所使用的模型名称

### 步骤 3：创建提示词模板

**提示词**（必填）

提示词决定 AI 如何处理文本。

**变量说明**：

- {&#123;selection&#125;}：选中的文本
- {&#123;clipboard&#125;}：剪贴板内容
- {&#123;datetime&#125;}：ISO 8601 格式的执行时间

**更多选项**（可选）：

- **系统提示词**：定义 AI 的角色和行为
- **最大令牌数**：生成的响应中可使用的最大令牌数
- **温度**：控制生成文本的随机性，值越高输出越随机
- **Top-P**：通过核采样控制生成文本的多样性

![TextGO AI 提示词编辑窗口](/screenshots/zh-CN/ai-prompt-editor.png)

## 使用提示词模板

创建提示词模板后，将其添加到快捷键规则：

1. 打开“全局快捷键”
2. 添加一条新规则
3. 在“执行动作”中选择创建的提示词模板
4. 保存规则

提示词模板始终在弹窗中显示结果，并可在弹窗中继续对话。
