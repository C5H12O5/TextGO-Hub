# 什么是 TextGO？

TextGO 是一款识别和处理选中文本的跨平台桌面应用。在任意应用中选中文本后，可通过快捷键、双击、Shift+点击或拖拽选中触发预设动作。

常见任务包括：

- 清理多余的空格和换行符
- 转换变量命名风格
- 打开选中的网址或文件路径
- 在指定网站中搜索选中文本
- 使用 AI 分析或润色文本

## 工作流程

TextGO 的工作流程：

```
1. 选中文本
   ↓
2. 触发（快捷键/双击/Shift+点击/拖拽）
   ↓
3. 识别类型（内置/自定义规则）
   ↓
4. 立即执行，或从工具栏中选择动作
   ↓
5. 处理结果（替换/弹窗/复制/历史记录）
```

## 使用场景

### 日常办公

- 打开网址、文件和文件夹
- 处理邮箱地址、ID 和时间戳
- 在常用网站中搜索选中文本

### 内容创作

- 清理并格式化文本内容
- 查询词汇释义和参考资料
- AI 辅助翻译、改写和润色

### 软件开发

- 转换命名风格
- 使用脚本格式化或转换代码片段
- 使用 JavaScript 自动执行跨平台键盘快捷键
- 使用 AI 解释或审阅选中的代码
